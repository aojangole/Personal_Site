# Ariko L’Ojangole: Portfolio

Personal portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All text, projects and contact details live in `src/data.js`.
Tap-to-contact links (email, WhatsApp, text, call) are built in `src/links.js`.

## Deploy

Hosted on Vercel. Every push to `main` redeploys automatically.
